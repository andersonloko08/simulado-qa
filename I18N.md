# Guia de Internacionalização (i18n) — InterviewOps Portugal

Este documento detalha a arquitetura de internacionalização da plataforma e o passo a passo para adicionar novos idiomas ao projeto.

---

## 1. Idiomas Suportados

### Interface (UI)

- `pt-br`: Português (Brasil) — **idioma fixo atual**.

### Conteúdo (questões e módulos)

O banco de questões (`json/questions.json`) armazena o conteúdo em **4 idiomas**:

- `pt-br`: Português (Brasil) — idioma padrão.
- `pt-pt`: Português (Portugal).
- `en-us`: English (United States).
- `en-uk`: English (United Kingdom).

---

## 2. Como Funciona a Engine de i18n

A engine de i18n está centralizada em `javascript/app.js`:

1. **`CURRENT_LANG`**: Constante fixa em `pt-br`. A interface é traduzida apenas para esse idioma por padrão.
2. **`resolveLang(category)`**: Função que decide o idioma do **conteúdo** de uma questão/módulo. Para categorias de Inglês (`English`, `english`) retorna `en-us`; para todas as demais retorna `pt-br`.
3. **`l(obj, category)`**: Função global para selecionar a string traduzida em objetos JSON multi-idioma.
   - Exemplo: `{ "pt-br": "Texto...", "en-us": "Text..." }` — retorna a versão do idioma resolvido, com fallback para `pt-br` e depois `en-us`.
4. **`t(key)`**: Função global para traduzir chaves de interface. Busca a chave na tabela `I18N.lang['pt-br']`; se não existir, retorna a própria chave.
5. **`applyTranslations()`**: Varre todos os elementos do DOM com o atributo `data-i18n="chave"` e atualiza o conteúdo textual ou HTML.
6. **`initI18n()`**: Deriva o caminho relativo do site a partir do `src` do próprio script, carrega `json/i18n.json`, e aplica as traduções.

### Idiomas do conteúdo

O banco de questões é **multi-idioma** (`lang` no JSON) e pode ser editado com a ferramenta Python em `tools/qa_editor/`. O front escolhe qual idioma exibir via `l(obj, category)`.

## 3. Passo a Passo para Adicionar um Novo Idioma de Conteúdo

Para adicionar um novo idioma ao **conteúdo** das questões (ex.: Espanhol `es-es`), siga estas etapas:

### Passo 1: Registrar o Idioma no `qa_core.py`

No arquivo `tools/qa_editor/qa_core.py`, adicione o código ISO do idioma à constante `LANGS`:

```python
LANGS = ["pt-br", "pt-pt", "en-us", "en-uk", "es-es"]
```

### Passo 2: Preencher as Traduções nas Questões

Use a GUI (`qa_gui.py`), o Web Admin (`qa_web.py` → `/admin`) ou edite diretamente o JSON adicionando o novo nó em `lang` de cada questão:

```json
"lang": {
  "pt-br": { "question": "O que é um teste de regressão?", "options": [...] },
  "en-us": { "question": "What is regression testing?", "options": [...] },
  "es-es": { "question": "¿Qué es una prueba de regresión?", "options": [...] }
}
```

> Dica: para preencher rapidamente os idiomas vazios copiando de um idioma-base, use `python qa_cli.py translate --base-lang pt-br` (apenas propaga, não traduz).

### Passo 3: Validar e Exportar

```bash
python qa_cli.py validate --full   # Exige conteúdo em todos os idiomas
python qa_cli.py stats             # Mostra preenchimento por idioma
python qa_cli.py export            # Gera artefatos para o front
```

## 4. Passo a Passo para Adicionar um Novo Idioma de Interface

### Passo 1: Adicionar as Chaves de Interface em `json/i18n.json`

Crie o nó com o código do novo idioma sob `"lang"`:

```json
{
  "lang": {
    "pt-br": { "home": "Início", "modules": "Módulos", ... },
    "es-es": { "home": "Inicio", "modules": "Módulos", ... }
  }
}
```

### Passo 2: Marcar Elementos no HTML (se criar novas páginas)

Em páginas HTML, adicione o atributo `data-i18n` em qualquer elemento de texto estático:

```html
<h1 data-i18n="minha_chave_titulo">Título Padrão</h1>
<button data-i18n="study_now">Estudar agora</button>
```

### Passo 3: Ajustar `applyTranslations` / idioma ativo

Para ativar a seleção dinâmica de idioma de interface, ajuste `app.js` para ler o idioma ativo de um cookie e atualizar `CURRENT_LANG` antes de `applyTranslations()`.

## 5. Testes e Validação Local

1. Rode um servidor local HTTP:
   ```bash
   python -m http.server 8000
   ```
2. Abra `http://localhost:8000` no seu navegador.
3. Verifique que a interface renderiza corretamente e que o conteúdo das questões usa o idioma esperado (inglês apenas na categoria English).
4. Valide o banco multi-idioma com `tools/qa_editor` (`python qa_cli.py validate --full`).
