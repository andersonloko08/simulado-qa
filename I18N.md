# Guia de Internacionalização (i18n) — InterviewOps Portugal

Este documento detalha a arquitetura de internacionalização da plataforma e o passo a passo para adicionar novos idiomas ao projeto.

---

## 1. Idiomas Suportados Atualidade

- `pt-br`: Português (Brasil) — Idioma padrão.
- `en-us`: English (United States).

---

## 2. Como Funciona a Engine de i18n

A engine de i18n está centralizada em `javascript/app.js`:

1. **`LANGS` e `LANG_NAMES`**: Arrays/Objetos que definem os idiomas suportados e seus rótulos para o menu drop-down na topbar.
2. **`storeGet('lang')` / `storeSet('lang')`**: O idioma ativo é persistido no cookie do usuário.
3. **`t(key)`**: Função global para traduzir chaves de interface. Busca primeiro em `I18N.lang[CURRENT_LANG][key]`, depois no fallback `pt-br`.
4. **`l(object)`**: Função global para selecionar a string traduzida em objetos JSON multi-idioma.
   - Exemplo: `{ "pt-br": "Texto...", "en-us": "Text..." }`.
5. **`applyTranslations()`**: Varre todos os elementos do DOM com o atributo `data-i18n="chave"` e atualiza o seu conteúdo textual ou HTML.
6. **`initI18n()`**: Carrega o arquivo `json/i18n.json`, lê o cookie de idioma ativo, renderiza o seletor na topbar e aplica as traduções.

---

## 3. Passo a Passo para Adicionar um Novo Idioma

Para adicionar um novo idioma (por exemplo, Espanhol `es-es` ou Francês `fr-fr`), siga estas etapas:

### Passo 1: Registrar o Idioma no `app.js`

No arquivo `javascript/app.js`, adicione o código ISO do idioma na constante `LANGS` e o nome exibido em `LANG_NAMES`:

```javascript
const LANGS = ['pt-br', 'en-us', 'es-es'];
const LANG_NAMES = {
    'pt-br': 'Português (BR)',
    'en-us': 'English (US)',
    'es-es': 'Español (ES)'
};
```

### Passo 2: Adicionar as Chaves de Interface em `json/i18n.json`

No arquivo `json/i18n.json`, crie o nó com o código do novo idioma sob `"lang"`:

```json
{
  "lang": {
    "pt-br": { ... },
    "en-us": { ... },
    "es-es": {
      "home": "Inicio",
      "dashboard": "Panel",
      "modules": "Módulos",
      "mock_interview": "Entrevista Simulada",
      "career_engine": "Motor de Carrera",
      "english": "Inglés",
      "gaps": "Brechas",
      "roadmap": "Hoja de Ruta",
      "study_now": "Estudiar ahora",
      ...
    }
  }
}
```

### Passo 3: Traduzir os Arquivos JSON de Conteúdo Dinâmico

Para que o conteúdo dos módulos e quizzes também apareça no novo idioma, adicione a chave do novo idioma nos arquivos JSON correspondentes:

- **`json/questions.json`**: Adicione o idioma nas perguntas em `lang`:
  ```json
  "lang": {
    "pt-br": { "question": "O que é um teste de regressão?", "options": [...] },
    "en-us": { "question": "What is regression testing?", "options": [...] },
    "es-es": { "question": "¿Qué es una prueba de regresión?", "options": [...] }
  }
  ```
- **`json/modules/*.json`**: Adicione traduções nos conceitos dos módulos.

### Passo 4: Marcar Elementos no HTML (se criar novas páginas)

Em novas páginas HTML, adicione o atributo `data-i18n` em qualquer elemento de texto estático:

```html
<h1 data-i18n="minha_chave_titulo">Título Padrão</h1>
<button data-i18n="study_now">Estudar agora</button>
```

---

## 4. Testes e Validação Local

1. Rode um servidor local HTTP:
   ```bash
   python -m http.server 8000
   ```
2. Abra `http://localhost:8000` no seu navegador.
3. Altere o idioma no seletor do topo. A página re-renderizará automaticamente com o novo idioma ativo.
